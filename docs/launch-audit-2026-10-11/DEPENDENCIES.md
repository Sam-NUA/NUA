# Dependency audit — 11 October 2026 (Melbourne)

Backend direct pinned-requirements audit: 117 packages checked, zero known vulnerabilities. The initial resolver-based scan reported only Starlette and is not accepted as complete coverage; the direct scan uses --no-deps --disable-pip and does not certify unlisted transitive packages. Frontend: 130 affected dependency entries before (4 critical, 82 high, 39 moderate, 5 low); 129 after (4 critical, 81 high, 39 moderate, 5 low). These are dependency entries, not distinct exploits. No ignore/baseline was widened.

Reachability: inspected production JavaScript source maps, imports, dependency graph, vercel.json and Electron main.js. Only Axios among flagged packages appears in emitted browser JavaScript. Absence from maps is evidence about this web build, not proof of safety for developer or desktop installations.

Axios 1.18.1 was updated to 1.20.0 within the existing major. Browser API calls are reachable. Node adapter, HTTP2 and proxy issues are outside the browser adapter path; prototype-pollution gadgets require another pollution source, which was not established. The patched release removes the reported advisory ranges. Maintainer source: https://github.com/axios/axios/security/advisories/GHSA-9fr6-4gfg-395g .

Vercel serves static CRA output, not webpack-dev-server or Electron. Remaining findings are open tooling/desktop risks. Malicious assets/dependencies or exposed developer servers can still reach tooling vulnerabilities. Desktop releases are not cleared for launch. Forced react-scripts@0.0.0 replacement and major Electron/Tailwind upgrades were not applied without compatibility testing.
