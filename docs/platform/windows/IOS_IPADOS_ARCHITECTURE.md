# iOS / iPadOS design only

Reuse shared React via a future Capacitor iOS target, following Android alignment. Keychain-backed credentials, app-bound permission prompts, signed distribution, background/reconnect behavior, receipt printer vendor SDKs, tap-to-pay/terminal certification and iPad layout QA are prerequisites. No Apple project, entitlements, provisioning profiles or device testing are provided by this package. Do not equate browser compatibility with native readiness.
